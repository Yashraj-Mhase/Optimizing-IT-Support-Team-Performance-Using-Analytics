2. Project Detailed description: 
   - Description: 
<br>

🔹 Week 1 – Data Understanding & Power BI Basics
In the first week, we were introduced to the project domain involving customer transaction issues handled through ticketing systems. We learned the basics of Power BI, including Ribbon, Power Query, Report, Table, and Model views. We also practiced extracting datasets from online sources and performed initial data cleaning using Power Query.

 <br>

🔹 Week 2 – Data Preprocessing Using Python
During the second week, we worked on data preprocessing using Python in VS Code. We learned to use Pandas and DataFrames to clean datasets by removing duplicates, handling null values, replacing values, trimming whitespaces, removing special characters, filtering rows, dropping unnecessary columns, and renaming fields. This improved our understanding of programmatic data cleaning.

<br>

🔹 Week 3 – Exploratory Data Analysis & Live Data
In the third week, we learned about Exploratory Data Analysis (EDA) and its importance in identifying patterns and insights before building dashboards. We practiced framing business questions from data and explored factors such as data distribution and relationships. We also learned how to import live data into Power BI using web sources and APIs.

<br>

🔹 Week 4 – GitHub, Zendesk & Tool Exposure
In the fourth week, we gained practical exposure to GitHub by creating repositories, organizing folders, and writing README files. We were introduced to Zendesk as a customer support and ticket management tool used by organizations to track issues, assign tickets, and measure performance. This helped us understand real-world ticketing systems.

<br>

🔹 Week 5 – Data Modeling & Relationships
During the fifth week, we studied different types of data such as numerical, categorical, and time-series data, and how they influence chart selection. We learned about primary and foreign keys, fact and dimension tables, and various relationships. We also explored star and snowflake schemas using Power BI’s Model View.

<br>

🔹 Week 6 – DAX, Measures & Dashboard Logic
In the final week, we focused on DAX concepts including implicit and explicit measures, CALCULATE, filters, slicers, and conditional formatting. We learned to create base and composite measures, apply business logic using IF and nested IF conditions, and understood how DAX interacts with the data model to build dynamic dashboards.
